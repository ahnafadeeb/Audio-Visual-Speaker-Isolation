# Start Here

Welcome to the comprehensive explanation guide for the **Audio-Visual Speaker Isolation** project. 

If you need to understand this project from scratch, as if you built every single line of code yourself, you are in the right place. Read these documents in order (01 to 15) to build a complete mental model of the theory, the machine learning models, the digital signal processing (DSP), and the web engineering that makes this project work.

### Recommended Reading Order:
1. **The 'Why'**: Start with `02_Problem_and_Big_Picture.md` to understand what we are solving.
2. **The 'What'**: Read `05_Theory_and_Concepts.md` and `07_Models.md` to understand the science.
3. **The 'How'**: Dive into `08_Code_Walkthrough.md` to see exactly how the code works.
4. **The 'Defense'**: Read `12_Viva_Questions.md` to prepare for any questions your professors might throw at you.
