# Glossary of Terms

* **AV-TSE**: Audio-Visual Target-Speaker Extraction. Using video (lips) to guide audio separation.
* **STFT**: Short-Time Fourier Transform. Breaking audio into small time chunks and analyzing the frequencies in each chunk.
* **Wiener Masking**: A mathematical filter used to suppress noise by comparing the power of the target signal to the total signal.
* **Schmitt Trigger**: A gate with two thresholds (hysteresis) to prevent rapid toggling on borderline signals.
* **SI-SDR**: Scale-Invariant Signal-to-Distortion Ratio. The primary metric for audio separation quality. Higher is better.
* **WER**: Word Error Rate. How many words a speech-to-text model (like Whisper) got wrong.
* **Web Audio API**: A high-level JavaScript API for processing and synthesizing audio in web applications.
